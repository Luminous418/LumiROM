Introduction¶

Welcome to the documentation for LumiROM - a custom ROM designed to bring One UI and Galaxy AI to low-end Samsung MediaTek devices.

LumiROM takes official Samsung firmware and reconstructs it from scratch, applying heavy optimizations, Galaxy AI features, Knox patches and EROFS filesystem compression to give your device a completely new, smooth experience.

Some of the special features of LumiROM are:

  • Galaxy AI: Call Assist, Writing Assist, Note Assist, Photo Assist, Transcript Assist and Browsing Assist - on devices that were never meant to have them.

  • Knox patches: Secure Folder, Samsung Health, Samsung Flow and more - working without root or extra modules.

  • Heavy optimization: 150+ bloatware apps removed, EROFS filesystem, deodexed system, CPU/GPU tuning and VoLTE fix.

This page is your starting point. Use the sidebar to navigate to any topic.

What does LumiROM do?¶

LumiROM automates the ROM reconstruction process from scratch, applying advanced patches and critical optimizations directly to the official Samsung firmware.

How it works¶

The build pipeline runs automatically via GitHub Actions (cloud) or locally on your Linux machine:

1

Firmware Download

Downloads the official Samsung firmware directly using Samloader, ensuring 100% base compatibility.

2

OTA Merging & Extraction

Merges cumulative OTA patches, extracts partition images and mounts them in a virtual Linux environment.

3

Optimizations & Tweaks

Applies heavy debloating (150+ apps), integrates Galaxy AI, patches Knox via Smali modifications, and tunes CPU/GPU via kernel.

4

EROFS Packaging

Compresses the filesystem using EROFS to save storage space on small partitions and speed up I/O.

🤖 Universal compilation

The whole build process runs automatically either in the cloud via GitHub Actions or locally on your computer using Linux or WSL - no special hardware required.
