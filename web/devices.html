Supported Devices¶

LumiROM is specifically designed and tested for popular low-end Samsung Galaxy models powered by MediaTek chipsets. All listed devices receive official builds.

Fingerprint on Display (FOD) Devices¶

These devices use an A34 base (FOD model) for optimal Fingerprint on Display compatibility.

Galaxy A32 4G

SM-A325F

Tuned for AMOLED screens and Fingerprint on Display (FOD) integrations using an A34 base.

Base: FOD (A34) ✓ Supported

Galaxy A32 4G (Latam)

SM-A325M

Latin American variant fully supported with regional-specific firmware bases.

Base: FOD (A34) ✓ Supported

Galaxy M32

SM-M325F

Massive battery managed more efficiently with custom refined power profiles.

Base: FOD (A34) ✓ Supported

Side Fingerprint Devices¶

These devices use an A24 base (Side-FP model) for optimal hardware compatibility.

Galaxy A22

SM-A225F

Excellent stability. Employs Side-FP base models modified to deliver the best hardware efficiency.

Base: Side-FP (A24) ✓ Supported

Galaxy A22 5G

SM-A226B

Optimized native 5G connectivity support and Kernel adaptations for EROFS mounting.

Base: Side-FP (A24) ✓ Supported

Galaxy F22

SM-E225F

Tailored hardware support and optimized drivers to power the 90Hz Fluid screen.

Base: Side-FP (A24) ✓ Supported

Base Information¶

💡 Base Information: Fingerprint on Display (FOD) devices will use bases from FOD models (e.g., A32 → A34 base). Side-FP devices will use Side-FP bases (e.g., A22 → A24 base). The base model determines which firmware is used as the source for patching.

The current base firmware versions in use are:

  • FOD base (A34): A346BXXUFFZD5 - security patch 05-04-2026

  • Side-FP base (A24): A245FXXUBFZD1 - security patch 05-04-2026
